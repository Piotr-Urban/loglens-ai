# LogLens AI

AI-powered platform for log analysis, anomaly detection, and incident investigation.

## Project goal

LogLens AI helps developers analyze application logs, group recurring errors,
detect unusual activity, and investigate incidents using evidence-based AI reports.

## Planned features

- Import logs from JSONL files
- Browse, search, and filter logs
- Group similar errors using message fingerprinting
- Detect anomalies in error frequency
- Automatically create incidents
- Generate AI incident reports based on collected evidence
- Ask questions about logs and incidents
